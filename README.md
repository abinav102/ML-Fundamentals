# ML-Fundamentals

Collection of foundational machine-learning and data-science projects.

## Contents

| File | Description |
|---|---|
| `Linear_Regression_Project.ipynb` | Linear regression with Scikit-learn |
| `NY_aIrBnBipynb.ipynb` | New York Airbnb pricing analysis |
| `ZomatoDataset.ipynb` | Zomato restaurant data — cleaning, EDA, visualisation, geospatial mapping |

## Tools & Languages

- Python · Pandas · NumPy · Scikit-learn · Seaborn · Matplotlib · Folium
- Jupyter Notebooks

## Setup

1. `pip install pandas numpy scikit-learn seaborn matplotlib folium`
2. Open the desired `.ipynb` in Jupyter or Google Colab and run cells sequentially.

## Limitations & Next Steps
